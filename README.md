# limits-log

Мод Claude Code: записывает лимиты подписки (окна 5 часов и 7 дней) в журнал и показывает по нему
в панели `/limits`, сколько осталось до сброса и как тратились прошлые недели.

## Установка

В строке ввода Claude Code в терминале:

```
/plugin install limits-log --marketplace justcatboy/claude-code-limits-log
```

На вопрос `Add marketplace?` ответьте `y`, затем выберите область — `user`, чтобы мод работал во
всех сессиях: лимит общий на аккаунт, а мод видит его только там, где загружен.

Из оболочки — `claude plugin install limits-log --marketplace justcatboy/claude-code-limits-log`.
В десктопном приложении: `+` у поля ввода → Plugins → Add marketplace
`justcatboy/claude-code-limits-log` → Add plugin.

Из папки, без установки (для разработки): `claude --plugin-dir <папка мода>` — только в эту сессию;
во все сессии — `CLAUDE_CODE_PLUGIN_DIRS` в блоке `env` пользовательских настроек:

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "<полный путь к папке мода>" } }
```

## Панель `/limits`

```
/limits [now|week]
```

| Режим | Клавиша | Что показывает |
| --- | --- | --- |
| `now` (по умолчанию) | `n` | текущую неделю и окно 5h: сколько осталось и хватит ли до сброса |
| `week` | `w` | законченные недели, последняя первой (вкладки — клавиши `1`–`9`) |

Панель показывает снимок на момент открытия, `r` пересчитывает его. Пример `now`:

```
Неделя 04.03 10:00 – 11.03 10:00 · 15%

Поровну
ср       чт      пт      сб      вс      пн      вт
████████▒▒▒▒▒▒▒░░░░░░░░▒▒▒▒▒▒▒░░░░░░░░▒▒▒▒▒▒▒░░░░░░░

По прошлой неделе
ср                чт    пт                пн        вт
████████░░░░░░░░░░▒▒▒▒▒░░░░░░░░░░░░░░░░░░▒▒▒▒▒▒▒▒▒░░░░░░

Сброс     через 5д 20ч
Сегодня   +11% · $34.00 · 120 сообщений
Можно     ~11% в день
Запас     хватит · к сбросу ~74%

Цена 1%   $3.14 · 11 сообщений
Остаток   85% ≈ $267 · 935 сообщений
Потрачено $47.10 · 5 сессий
Модели    claude-opus-5-5 +15%

По дням …

Окно 5h 11:20–16:20
5h ███████░░░  68%
Остаток   ~32%
Кончится  к 15:15
```

**Полосы** — недельный лимит, поделённый на 7 дней. Ширина отрезка — бюджет дня, закрашено —
потрачено. Прошедшие дни занимают столько, сколько потрачено, остаток делится между сегодняшним и
будущими днями: «Поровну» — поровну, «По прошлой неделе» (или «По N прошлым неделям», до 5) — так,
как лимит тратился в эти же дни прошлых недель.

**День недели** — 24 часа от начала недели (от сброса), а не календарный день: у недели со сбросом в
10:00 день идёт с 10:00 до 10:00 и подписан датой начала.

**Строки:**

- **Сегодня** — прирост 7d, трата и сообщения за текущий день недели.
- **Можно** — остаток 7d, делённый на дни до сброса.
- **Запас** — ожидаемый процент к сбросу: сейчас плюс средний прирост прошлых недель в оставшиеся
  дни (пока прошлых недель нет — по темпу этой). `хватит` — до 85%, `впритык` — до 100%,
  `не хватит` — с моментом, когда будет 100%, `исчерпан`.
- **Цена 1%** — сколько $ и сообщений уходит на 1% 7d, по всему журналу. **Остаток** — то же для
  оставшихся процентов.
- **Потрачено** — стоимость недели по ценам API (как в `/cost`) и число сессий.
- **Модели** — прирост 7d по моделям.
- **Окно 5h: кончится** — когда окно дойдёт до 100% при нынешнем темпе, если раньше сброса.

«Сообщение» — ход основного цикла: сообщение пользователя и вся работа Claude над ним. С числом
отправленных сообщений совпадает не точно: фоновые задачи тоже начинают ходы, а ходы субагентов не
считаются.

## Журнал

Файлы мода лежат в папке `limits-log` каталога профиля (`$CLAUDE_CONFIG_DIR`, иначе `~/.claude`).
Журнал — `limits-log/log/<месяц UTC>/<сессия>.jsonl`: каждая сессия пишет свой файл, анализ читает
все и убирает повторы (один и тот же сдвиг могут записать несколько сессий).

Формат — [JSON Lines](https://jsonlines.org/), одна запись на строку. Записи двух типов (`kind`).

### `limits` — состояние лимитов

Пишется, когда окно сдвинулось на целый процент (в том числе вниз — сброс вне расписания). Не
пишется, если окон нет, какое-то окно уже закончилось или окна те же, что в прошлой записи сессии.

```json
{"v":4,"kind":"limits","ts":"2026-03-04T12:34:06Z",
 "windows":[{"kind":"five_hour","pct":34,"resetsAt":1772636400},
            {"kind":"seven_day","pct":6,"resetsAt":1773223200}],
 "model":"claude-opus-5-5","effort":"medium","session":"0b6e2c1a-…",
 "costUsd":5.6066,"contextTokens":192782,
 "usageTotals":[{"session":"0b6e2c1a-…","turns":64,"usage":[…]},
                {"session":"7f3a9d52-…","turns":12,"usage":[…]}]}
```

| Поле | Что это |
| --- | --- |
| `v` | версия формата записи |
| `ts` | время записи, ISO UTC |
| `windows` | все окна лимитов из ответа API: `kind` (`five_hour`, `seven_day`, `spend_limit` или новое), `pct` — израсходовано, %, `resetsAt` — сброс, unix-секунды |
| `model`, `effort` | модель и effort основного цикла |
| `session` | сессия, сделавшая запись |
| `costUsd` | накопленная стоимость сессии по ценам API |
| `contextTokens` | заполнение контекста по последнему ответу, токены |
| `usageTotals` | накопленные итоги всех активных сессий: `turns` — ходы основного цикла, `usage` — токены. Расход между записями — их разница |

### `session` — итог сессии

Пишется при завершении сессии. Если завершение не дошло (сбой, закрытый терминал), итог дописывается
позже с `reason: "orphan"`. Итог накопительный: из записей одной сессии верна последняя.

```json
{"v":4,"kind":"session","ts":"2026-03-04T17:40:02Z","session":"0b6e2c1a-…",
 "project":"C:\\projects\\my-app","start":"2026-03-04T11:31:10Z","end":"2026-03-04T17:40:01Z",
 "reason":"prompt_input_exit","turns":64,"aborted":2,"errors":0,"activeMs":2871000,
 "costUsd":14.21,"model":"claude-opus-5-5","effort":"medium","usage":[…],
 "tools":{"Read":41,"Edit":30,"PowerShell":52,"Agent":1},"compactions":0,
 "maxContextTokens":319150}
```

| Поле | Что это |
| --- | --- |
| `project` | рабочая папка сессии |
| `start`, `end` | начало и последняя активность, ISO UTC |
| `reason` | `prompt_input_exit`, `clear`, `resume`, `logout`, `other` или `orphan` |
| `turns`, `aborted`, `errors` | ходы основного цикла, из них прерванные и с ошибкой |
| `activeMs` | сколько модель работала, мс |
| `costUsd` | итоговая стоимость сессии по ценам API |
| `usage` | токены по моделям, основной цикл и субагенты |
| `tools` | вызовы инструментов по имени |
| `compactions`, `maxContextTokens` | сжатия контекста и наибольшее его заполнение |

**Токены** (`usage`) — список по моделям: `model`, `agent: true` у субагентов, `turns`, `input`,
`output`, `cacheRead`, `cacheWrite`.

Тексты промптов и ответов мод не пишет — только числа и имена.

**Правила формата:** поля только добавляются и не меняют смысл, `v` растёт при смене набора полей.
Читатель обходится без любого поля и пропускает незнакомые `kind` и битые строки.

## Ограничения

- Мод видит лимиты только в сессиях, где загружен (см. «Установка»).
- Точность — целый процент: движок не сообщает сдвиги меньше.
- Расход в claude.ai (веб, приложения) делит те же лимиты, но мод его не видит.
- Fast mode не записывается: движок не сообщает его модам.
